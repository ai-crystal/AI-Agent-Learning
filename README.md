## 知识体系

这四册不是简单的“入门、进阶、深入”，而是四个不同的工程视角：

```text
基础能力       知识获取        生产运行        企业交付
从语言模型到智能体  →  RAG 与上下文工程  →  Agent 工程化  →  Agent 企业实战
```

- 第一册解决“Agent 是什么，怎样思考和行动”；
- 第二册解决“模型不知道的知识怎样被检索、重排和放进上下文”；
- 第三册解决“Agent 怎样在权限、状态和失败中可靠运行”；
- 第四册解决“这些能力怎样进入真实企业流程并验收”。

每册都保持独立，正文不引用另一册；根目录只负责系列导航。

## 阅读路线

- 第一次接触 Agent：从第一册的前言和第 0 章开始。
- 已经有原型，想把 RAG 做准：读第二册第 2—7 章。
- 准备接入真实系统：读第三册的运行时、权限、观测和可靠性章节。
- 面向企业项目：读第四册的案例和交付模板。
