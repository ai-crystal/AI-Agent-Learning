# 第 6 章 可观测性

## 6.1 日志不够

普通服务日志通常记录“请求进来、返回什么”。Agent 还需要知道：

- 模型看到了什么上下文；
- 它生成了什么动作；
- 工具收到了什么参数；
- 工具返回了什么、是否截断；
- 权限判断为什么通过或拒绝；
- 每一步消耗了多少 token、多少时间、多少钱。

没有这些，失败只能被描述成“模型今天不太稳定”。

## 6.2 一条 trace

```json
{
  "trace_id": "trace-2026-1117-0042",
  "task_id": "task-017",
  "tenant_id": "t-42",
  "steps": [
    {"step": 1, "type": "model", "prompt_version": "runner@v3",
     "input_tokens": 1820, "output_tokens": 140, "latency_ms": 920},
    {"step": 2, "type": "tool", "name": "get_order",
     "args_hash": "sha256:...", "status": "ok", "latency_ms": 184},
    {"step": 3, "type": "tool", "name": "search_policy",
     "status": "ok", "results": ["E1", "E2"], "latency_ms": 310},
    {"step": 4, "type": "approval", "decision": "approved",
     "approver": "u-201", "at": "10:22:11"}
  ],
  "outcome": "refund_submitted",
  "total_usd": 0.12
}
```

参数是否保存原文取决于敏感度。高敏参数可以只存哈希、字段名和脱敏值；但调试时仍需要能复现。通常需要分级权限：普通运维看摘要，安全审计看受控原文。

## 6.3 指标

至少区分四类指标：

- **任务**：成功率、完成率、人工接管率、平均步数；
- **工具**：调用成功率、P95 延迟、错误分类、重复执行次数；
- **模型**：token、延迟、格式错误率、上下文超限率；
- **业务**：解决率、用户满意度、退款准确率、工单回退率。

只看模型延迟会漏掉工具排队；只看任务成功率会掩盖某类高风险请求全部被转人工。

## 6.4 失败分类

“失败”不是一个指标。可以按责任层分类：

```text
permission_denied
tool_timeout
tool_schema_error
context_overflow
model_format_error
policy_missing
external_service_error
human_rejected
```

分类后才能真正比较版本：一次发布让总成功率高 2 个点，但工具超时增加一倍，不能算纯粹改进。

## 6.5 回放

回放不是重新调用模型，而是用保存的输入、版本和工具结果重建当时的决策环境。它至少需要：

- 模型与提示版本；
- 上下文快照或可重建的引用；
- 工具参数和结果；
- 权限与租户；
- 代码版本。

回放可以回答“如果当时模型没有超时，会不会做出不同选择”，也可以用于评测回归。没有版本记录，回放只是猜。

## 6.6 隐私与保留期

trace 可能包含用户数据。需要：

- 默认脱敏；
- 按角色限制访问；
- 设置保留期和删除策略；
- 对导出、截图和分享做审计；
- 不把密钥、完整凭据写进日志。

可观测性不能以“为了调试”为理由无限收集敏感信息。

## 6.7 本章的结论

可观测性把 Agent 的行为从“黑箱回答”变成可解释的执行记录。trace 记录每一步，指标衡量趋势，失败分类定位责任层，回放支持复现和回归。

下一章会把这些记录用于评测：不是只看一次回答像不像，而是看整条链路在固定任务集上的表现。

## 6.8 SLO 与告警

可以为任务定义服务水平目标：

```text
P95 任务完成时间 < 90 秒
工具错误率 < 2%
权限拒绝误判 < 0.5%
单任务成本 P95 < 0.30 美元
```

告警应绑定可行动的原因，例如“退款工具连续 5 分钟 5xx”或“某租户越权拒绝突然升高”，而不是只报“成功率下降”。没有上下文的告警会把值班人引向错误的层。

## 6.9 关联 ID

用户请求、任务、trace、工具调用和外部系统 ID 要能互相关联。客服看到一条回答，可以定位到任务；工程看到一条工具错误，可以找到同一请求的模型步骤。缺少关联 ID，跨系统排错只能靠时间猜。
