# 前言

企业 Agent 项目和演示项目最大的差别，不是模型更大，而是约束更多：数据属于谁、谁可以看、出问题谁负责、什么时候必须停下来找人、上线后怎样证明它真的减少了工作。

本书用六个案例讨论这些约束。案例中的公司、订单、合同、指标和数字都是教学虚构；架构、权限检查、失败处理和验收方法是可复用的。读者不应把案例数值当成行业基准。

每个案例尽量回答同一组问题：

1. 用户真正要完成什么，不是“让 Agent 回答什么”；
2. 哪些数据能进来，哪些必须在检索前过滤；
3. 哪些动作只能建议，哪些可以自动执行；
4. 失败时怎样降级、恢复和转人工；
5. 用什么指标验收，怎样防止回归。

这些问题的答案往往不在模型里，而在业务流程、数据契约和组织责任里。一个 Agent 项目如果只讨论提示词，通常还没有进入实施阶段。
